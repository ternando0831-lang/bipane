# Security Policy

English | [日本語](#日本語)

## Supported versions

Only the latest release receives security fixes. Bipane updates itself automatically (Settings → About), so keeping automatic updates on is usually all you need.

## Reporting a vulnerability

Please do not report security problems in public places such as social media or forums.

Report it privately in one of these ways:

- On GitHub: the **Security** tab of this repository → **Report a vulnerability** (only you and the author can see the report)
- By email: the feedback address shown in the app (**Settings → Feedback**)

Please include:

- the versions of Bipane and Windows
- what the problem is and how to reproduce it
- what someone could do by exploiting it

Bipane is made by one person, so a reply may take some time, but every report is read. Please allow reasonable time for a fix to be released before you disclose the problem publicly.

Problems in bundled third-party software (Electron / Chromium, 7-Zip) can also be reported to those projects directly.

# 日本語

## 対象の版

セキュリティの修正は最新の版にだけ行います。Bipane は自動で更新されるので（設定 → バージョン情報）、自動更新をオンにしておけば通常はそれで足ります。

## 脆弱性の報告

セキュリティ上の問題は、SNS や掲示板など公開の場所には書かないでください。

次のどちらかの方法で、非公開でお知らせください。

- GitHub: このリポジトリの **Security** タブ →「**Report a vulnerability**」（報告者と作者だけが見られます）
- メール: アプリに表示しているフィードバックの宛先（**設定 → フィードバック**）

次の内容があると助かります。

- Bipane と Windows のバージョン
- 問題の内容と再現の手順
- 悪用されると何ができてしまうか

個人で開発しているため返信に時間がかかることがありますが、報告はすべて読みます。修正版を出すまでの間、問題の公表はお待ちください。

同梱している第三者のソフトウェア（Electron / Chromium、7-Zip）の問題は、それぞれのプロジェクトにも直接報告できます。
